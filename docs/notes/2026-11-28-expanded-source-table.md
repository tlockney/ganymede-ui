## 2026-11-28, Expanded view for long source and tables (#822)

Follow-up from `#813` (part of `#800`): code cells longer than 20 lines and table outputs past 15 rows or overflowing their `32em` box now open in a full-window modal view instead of fighting narrow page cards or scrolling inside the page.

- **Shared registries (`src/lib/editor-setup.ts`).** Language, theme, and default CodeMirror extension construction moved out of `src/lib/jupyterlab.ts` so both inline cells and `ExpandedView` share syntax highlighting, line numbers, themes, and DuckDB SQL support without pulling JupyterLab's notebook runtime into standalone editor tests. `src/lib/wrap-code.ts` adds `subscribeWrapCode` so modal controls stay in sync with the global Wrap Code toggle.
- **Long source bar (`src/lib/source-expand.ts`).** Code cells longer than `SOURCE_LINES = 20` (uncollapsed) insert a `.gn-source-bar` above `.jp-Cell-inputWrapper` (right after `.gn-cell-meta`, with desktop margin clearing the hover toolbar). Capture-phase stop guards on `mousedown`, `pointerdown`, `dblclick`, and `focusin` prevent tapping an inactive cell's bar from expanding `.gn-cell-meta` mid-tap. Short cells keep **Expand Source** in `CellMenu` and the command palette (`expand-source`).
- **Table expansion (`src/lib/table-output.ts`, `src/lib/output-frames.ts`, `src/lib/output-labels.ts`).** `RenderedTable` exposes a `WeakMap` lookup (`tableWidgetFor`) plus `tableTitle`, `resource`, `trusted`, `kernel`, `total`, `shownCount`, `viewState`, and `restoreViewState` without altering `.gm-table-footer` text. `output-labels.ts` checks `TABLE_EXPAND_ROWS = 15`, truncated embedded rows (`total > shown`), wide outputs, and scroller/HTML table overflow to render an **Expand table** button inside `.gn-output-bar`. Sandboxed HTML table frames accept `overflowX: 'auto'` inside `ExpandedView` so wide columns scroll inside the frame.
- **Full-window view (`src/components/ExpandedView.tsx`).** Rendered outside JupyterLab's `contain: strict` `.jp-Notebook` container at `z-index: 95` with `useModalFocus`, capture-phase `Escape` dismissal (respecting IME composition and higher `.sheet-backdrop` / `.popup-menu-backdrop` layers), live Yjs-bound CodeMirror editing (`ybinding`) with `Wrap Code`, or `RenderedTable` / HTML table rendering that syncs page and sort state back on close. Wired into `NotebookPane`, `JournalView` (read-only), and `DuckdbConsole`.
- **Responsive styling & verification.** Desktop, `390px` phone (`touch-ui`), and `497px` iPad Split View dark/light layouts verified via Vitest unit/component/contrast suites and Playwright E2E (`e2e/expanded-view.spec.ts`), including sticky opaque table headers and 44px touch targets with zero horizontal page overflow.
