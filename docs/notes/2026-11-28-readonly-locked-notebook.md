## 2026-11-28, Read-only display for notebooks owned by another Ganymede server (#839)

Implemented read-only state when a notebook's contents model reports `writable: false` or its room turns read-only while another Ganymede server on the same machine holds its room lock (companion to `tlockney/ganymede#967`):

- **Read-only guard (`src/lib/room-offline.ts`):** Extracted `createReadOnlyGuard` from `watchOffline` so both offline machines (`#701`) and locked notebooks (`#839`) share one lock mechanism without touching `metadata.editable` or emitting Y-doc updates. It also exits edit mode when locking and locks new cells arriving from the owner's saves while read-only, then restores each cell's editable metadata cleanly on unlock.
- **Writability watcher (`src/lib/room-readonly.ts`, `src/lib/room.ts`):** Extended `trustFromFile` to pass back `file.writable` on room open with no extra request, and added `watchWritable` to watch both the contents API's `writable` flag (`1 s` cadence while read-only so notebooks unlock without a reload once the owner lets go, `5 s` while writable in a room, plus `focus` / `visibilitychange`) and room Yjs `state` signals (`read_only` / `readonly` / `writable` / `save_error` naming another server / `path` / `hash`).
- **UI & controls (`NotebookPane`, `JournalView`, `Toolbar`, `header-status`, `palette`, `cell-gutter`, `jupyterlab`, `App`):** Disabled editing, Run, Run All, cell gutter Run buttons (visibly disabled and refreshed on lock transitions), cell toolbar move/duplicate actions, CellMenu, KeyboardBar, CommandPalette mutating/run entries, Save, Rename, and kernel switching while read-only, and added `.readonly-banner` matching `.machine-banner` (verified by `src/styles/contrast.test.ts`).
- **Native Apple chrome (`PageState.swift`, `RunMenu.swift`, `NativeChrome.swift`, `IPadChrome.swift`, `HeaderStatus.swift`):** Propagated `readOnly` in `PageState` so native Run buttons, Cell menus, Save, Rename, Change Kernel, and the status line/bar reflect read-only state in the Mac, iPad, and iPhone apps.
- **Tests & docs:** Added Vitest coverage across `room-readonly.test.ts`, `room-offline-notebook.test.ts`, `NotebookPane.test.tsx`, `Toolbar.test.tsx`, `JournalView.test.tsx`, `palette.test.ts`, `header-status.test.ts`, `cell-gutter.test.ts`, `jupyterlab.test.ts`, and `PageStateTests.swift`, plus an Unreleased note in [docs/apps.md](../apps.md).
