## 2026-11-28, Journal view follow-ups (#702)

Completed the follow-up items left from the initial journal view (#184) and aligned room offline handling across journal and notebook views:

- **Fresh-kernel stamp & fingerprint verification (`src/lib/journal.ts`, `src/components/JournalView.tsx`, `src/styles/app.css`):** Implemented `murmur2` (seed 0) and `sourceFingerprint` (`v1:` over UTF-8 byte lengths of cell type and source) matching Ganymede's `ganymede_nbformat::hash`. `JournalView` reads `metadata.ganymede` on load and `metadataChanged`, showing the **"Ran from a fresh kernel"** badge only when `clean_run` has a `v1:` fingerprint matching the current cells and the notebook is backed by an open room. Stamps that are missing a fingerprint, malformed, mismatched, from an unknown `v<digits>:` version, or read via `GET /api/contents` with no room open are treated as stale/unverified and omitted from the current badge.
- **Runner attribution in the status line (`src/lib/journal.ts`, `src/components/JournalView.tsx`):** `useCells` watches cell `ymodel` key updates (`execution_state`, `execution_by`) and reads `execution_by` only while `executionState === 'running'`. `runningLine` names the active runner (`execution_by`) and falls back to `"Someone"`, rather than using the cell's author metadata.
- **Notebook view read-only while room reconnects (`src/lib/room-offline.ts`, `src/components/NotebookPane.tsx`):** Added `isRoomLive` and `watchRoomConnection` (using `watchLive` when available, falling back to `connected`/`onConnection`) and generalized `watchOffline` + `NotebookPane` beyond connected machines so any room that disconnects or is resyncing (`!isRoomLive(room)`) puts Notebook view into read-only mode via `createReadOnlyGuard`, hides the keyboard bar, disables editing/running commands and cell controls/menu/gutter, and shows a reconnecting banner until the room is live again.
- **Apple menus & tests (`apple/Sources/Ganymede/IPadChrome.swift`, `apple/Tests/GanymedeTests/PageStateTests.swift`):** Verified Mac `JournalCommand` and `PageState.journal` from #725, added the matching `IPadJournalButton` to `IPadCommands`'s View menu (`CommandGroup(after: .sidebar)`), and expanded `PageStateTests` to cover `journal` toggle states, symbols, and `editsCells` edge cases.
