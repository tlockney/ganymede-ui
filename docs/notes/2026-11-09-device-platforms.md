## 2026-11-09, Device API platforms in the guide (#431)

The Device API guide opened with "the iPad and iPhone app" and never said
the API exists only on Apple platforms. It now names the Mac too and
carries a note: macOS and iOS only, for now; in any other browser only
the no-permission subset answers, through web APIs. ganymede-device's
README and reference say the same (tlockney/ganymede-device#117).
