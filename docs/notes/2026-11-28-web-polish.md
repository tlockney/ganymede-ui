## 2026-11-28, Web polish: headings, eyebrow, quiet switch, sheet clearance, Find flash (#897)

Follow-up polish for the Mac redesign (`#897`, `#866`, `#891`):

- **Moon-cream headings in dark mode (`#897`):** Added `--heading` (`var(--text)` in light, `var(--brand-cream)` `#f4e9d8` in dark) in `src/styles/app.css` and applied it to `.notebook-page .jp-MarkdownOutput h1–h6`, live Markdown `.cm-md-live .cm-md-h` in `src/styles/jupyter.css`, and `.journal-title` and `.journal-rendered .jp-RenderedMarkdown h1–h6` in `src/styles/app.css`. `src/styles/contrast.test.ts` verifies both colors and 4.5:1 contrast against both window and cell surfaces.
- **Orange mono eyebrow with provenance (`#897`):** Switched `.title-eyebrow`, `.page-eyebrow` and `.journal-eyebrow` in `src/styles/app.css` from `var(--meta-color)` to `var(--accent-text)` (darker orange `#924900` on light, `#fbb064` on dark; `contrast.test.ts` checks `.title-eyebrow` on `--toolbar-bg` as well as all three against `--window-bg`). Updated `journalHeader` in `src/lib/journal.ts` to append `Kept with <by>` to `eyebrow` when agent metadata records `by` and omit it otherwise, with tests in `src/lib/journal.test.ts`.
- **Quiet cell selection when switching from Journal to Notebook (`#897`):** `NotebookPane`'s `goToCell(index, true)` (used only on returning from the journal) previously ran `notebook.mode = 'command'`, `cell.activate()` (focusing CodeMirror), and `notebook.activate()` (focusing the cell node, which matches `:focus-visible` when driven from the native toolbar or after `Open as Notebook` unmounts). Changed the `flush` path to `notebook.setMode('command', { focus: false })` and `notebook.select(cell)` without calling `cell.activate()` or `notebook.activate()`, keeping the quiet 1px `--cell-selected-border` until keyboard navigation or editing occurs.
- **Sheets and command palette clear the 64px eyebrow header (`#866`):** Moved `--toolbar-h: calc(64px + var(--safe-top))` back from `:root:not(.touch-ui) .main:has(.toolbar .title-eyebrow)` to `:root:not(.touch-ui):has(.toolbar .title-eyebrow)` in `src/styles/app.css` so sheets and the command palette outside `.window` also clear the taller toolbar, while pinning `.sidebar-titlebar` to `calc(52px + var(--safe-top))` so sidebar rows do not shift (`#812`). Verified in `e2e/journal.spec.ts`.
- **No "No matches" flash in Find while a notebook opens (`#891`):** Correcting `docs/notes/2026-11-27-mac-find-tab.md`: `App` no longer answers `find-in-notebook` with `{query, matches: [], more: 0}` whenever no controller is mounted. `NotebookPane` now reports `onLoadError(!!error)` and `App` tracks `failedPane` keyed by backend and path, keeping `notebookFind: null` (`"Searching…"`) while a notebook opens, answering empty only once opening fails, and resetting back to waiting on Retry or notebook switch.
