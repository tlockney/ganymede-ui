## 2026-11-09, Folders in the apps (#429)

ganymede-device's Phase 3 added folder bookmarks (ganymede-device#102):
`device.folders.pick` shows the system folder picker and keeps the
folder for the notebook, and a `Folder` lists, reads, writes and removes
inside it only. `KernelHost`'s default bridge now calls `addFolders()`.
The picker is the consent, so there is no ledger prompt, usage string or
entitlement: the Mac app isn't sandboxed, and on iOS the document picker
hands over a security-scoped URL that the bridge bookmarks.

Grants live in their own store, beside the ledger's. Settings › Device
reads both: `DeviceGrants` takes a `FolderGrants` as well as a ledger,
lists a notebook that has only folders, and Revoke and Revoke All take
folders away too.

The pins move to ganymede-device's main, docs/device.md's table is
regenerated and gains a "Folders" section, and the `hello` list in
`KernelHostTests` adds the folders methods (`folders.pick` last, as a
dialog). By-hand checks are on #399 (Mac) and #273 (iPad, iPhone).
