## 2026-11-09, ⌘W closes the active tab (#407)

⌘W quit the Mac app. `CommandGroup(replacing: .saveItem)` replaces the
whole group, and on macOS that group also holds File > Close, so the
app had no Close of its own; and the app delegate quit after the last
window closed. The File menu now has its own Close (⌘W), which sends
`performClose` to the key window: with AppKit's window tabs that is the
active tab only, and the save prompt still runs. The app now keeps
running with no windows, like other Mac document apps.

Replacing a SwiftUI command group drops every system item in it; check
Apple's list for the placement before replacing one.
