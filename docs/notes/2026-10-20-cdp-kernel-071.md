## 2026-10-20, cdp-kernel 0.7.1 (#99)

The in-page kernel now uses `@tlockney/cdp-kernel` 0.7.1, the first
release whose `startBrowserKernel` takes `preload`, `host` and
`capabilities` (cdp-kernel#384), which ganymede-device's `device` global
needs. CI's server kernel for the e2e suite moves from 0.6.0 to 0.7.1 too,
so both kernels are the same release.

`CdpBrowserKernel` passes none of the new options yet. Where they go
depends on how the Apple apps keep outputs away from the native bridge:
with a hidden kernel WebView, the UI page's kernel never gets a host, so a
seam here would be the wrong place. ganymede-device also isn't
consumable as a package yet (its review, finding 5).
