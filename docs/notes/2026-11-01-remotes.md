## 2026-11-01, Remotes in the apps (#120)

Settings in the Mac and iPad apps now keep a list of remotes instead of one kernel server. A remote has a name, an optional Jupyter or Ganymede server, and optional SSH (host or `~/.ssh/config` alias, user, port). One remote with a server is chosen for kernels, as the kernel server was. File > New Terminal On lists every remote with a server. SSH terminals come with #121, which also adds iOS keys.

Notes:

- `RemoteStore` keeps the list as JSON in UserDefaults and each server token in the keychain under `remote.<id>`, behind a `SecretStore` protocol so tests use memory instead of the keychain.
- On first launch the old `kernelServer` URL and token become one remote, chosen for kernels. The old items are removed only after the new ones are written, so a locked keychain means a retry next launch rather than a lost token.
- Changing the kernel remote, or the server URL or token of the remote kernels run on, restarts the server (and shuts down running kernels), as saving the kernel server did. Editing any other remote doesn't.
- A terminal window restored from before this change was for the kernel server, which no longer exists as a target. It opens as a local terminal.
