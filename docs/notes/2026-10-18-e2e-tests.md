## 2026-10-18, end-to-end tests (#5)

`e2e/` is a Playwright suite that CI runs against the production build
and a real `ganymede serve` 0.2.0 with cdp-kernel 0.6.0's Node kernel,
with no Python. It replaces `scripts/screenshots.mjs`, which needed a
hand-started server with ipykernel. Covered: Run All with stream,
`execute_result` and HTML output; saving with Ctrl/Cmd+S, checked on
disk and after a reload; the in-browser JavaScript kernel in light and
dark; screenshots, uploaded as a CI artifact.

- Selectors use roles, visible text and JupyterLab's own classes
  (`.jp-Cell`, `.jp-OutputArea-output`, `[data-mime-type]`), so the
  suite outlives the move off jupyter-react (#9) and checks it.
- cdp-kernel needs Node 22.18 or newer, not 24; CI uses 24 like the
  rest of the workflow.
- `@playwright/test` is pinned to 1.56.1, the version ganymede's
  `validation/` uses, so the same Chromium build serves both.
- CI installs Ganymede with `site/install.sh` from the release tag and
  `--no-kernel`, then cdp-kernel from npm; both versions sit in the job's
  env.
