## 2026-11-07, Apps on macOS 26 and iOS 26, Mac app arm64 only (#356)

- Thomas decided the apps require macOS 26 and iOS 26 and that the Mac app
  is Apple silicon only. macOS 26 is the last release Intel Macs get, and
  every Apple silicon Mac runs it. The Ganymede server and CLI keep Intel
  and older systems; only the apps move.
- `project.yml`: deployment targets 26.0, `ARCHS[sdk=macosx*]: arm64`.
  `release-app.sh` fails unless `lipo -archs` says `arm64`.
- Removed what only macOS 13 / iOS 16 needed: the `showSettingsWindow:`
  fallback (Settings opens through `openSettings` only) and the
  `#available` checks around `inactiveSchedulingPolicy` and
  `isInspectable`. `onChange(of:)` uses the two-value form, and
  `NSApp.activate()` replaces `activate(ignoringOtherApps:)`, both
  deprecated since macOS 14.
- `vite.config.ts` drops the `safari16` build target, so the build uses
  Vite 8's default, Baseline Widely Available: Chrome and Edge 111,
  Firefox 114, Safari 16.4, all released in March to June 2023. The pin
  was only there for the apps' macOS 13 / iOS 16 web view (Safari 16.0).
  For browsers the floor moves up by a few months of releases; each of
  those browsers updates itself, and JupyterLab 4, which the UI builds
  on, already assumes current browsers.
- Kept: the Kernel Log's end-marker follow logic (2026-11-05 notes). The
  scroll geometry APIs could replace it, but whether they report "at the
  end" before or after new lines arrive needs a check on a device, so
  that waits for a change that can be tried by hand.
- ganymede-ffi's XCFramework is arm64 only from ganymede#455.
  `GANYMEDE_REF` points at that merge on ganymede's main until the next
  Ganymede release, and the `x86_64-apple-darwin` rustup target is gone
  from `bootstrap.sh`, CI and both release jobs: one of the four Rust
  builds each app build ran.
- With the two-value `onChange` closures, the Mac window's `body` (one
  modifier chain of about 40 calls) hit "unable to type-check this
  expression in reasonable time" in Xcode 26.6. It is now three computed
  properties, each a shorter chain.
