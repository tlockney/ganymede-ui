## 2026-11-13, bundle cdp-kernel 0.11.0 (#594)

cdp-kernel 0.11.0 ships `jupyter.table`, `jupyter.sql` and
`jupyter.chart` (tlockney/ganymede#747). The apps bundle it, and CI's
server-kernel tests use it, so the table renderer (#581) shows real
kernel output. Its own dependency on TypeScript is now a `^6.0.3` range
instead of an exact version, which the lockfile records.

Network: in the apps (cdp-kernel's browser target) these helpers load
their libraries on first use, only when a cell calls them.
`jupyter.chart` imports `npm:vega@6`, `npm:vega-lite@6` and
`npm:linkedom@0.18` through the kernel's CDN (esm.sh by default);
`jupyter.sql` imports `npm:@duckdb/duckdb-wasm@1.29.0` the same way, and
duckdb-wasm then loads its worker and wasm from cdn.jsdelivr.net, a host
the in-app kernel didn't contact before. vega and vega-lite float within
major 6. Bundling them for offline use is a later step on
tlockney/ganymede#747.
