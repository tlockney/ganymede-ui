## 2026-11-13, bundle cdp-kernel 0.11.0 (#594)

cdp-kernel 0.11.0 ships `jupyter.table`, `jupyter.sql` and
`jupyter.chart` (tlockney/ganymede#747). The apps bundle it, and CI's
server-kernel tests use it, so the table renderer (#581) shows real
kernel output. Its own dependency on TypeScript is now a `^6.0.3` range
instead of an exact version, which the lockfile records.
