## 2026-10-19, the macOS app (#38)

`apple/` holds a SwiftUI app that links ganymede-ffi (tlockney/ganymede
#157) and shows this repo's build in a `WKWebView`, the plan from
tlockney/ganymede#59.

- No `.xcodeproj` in git: XcodeGen generates it from `project.yml`, which
  diffs and merges as text. `scripts/bootstrap.sh` builds the inputs into
  `apple/build/` (gitignored).
- The server runs on loopback with a token, through the same cookie
  login as `ganymede ui`, so the web app needs no changes. The saved port
  keeps the origin stable; a new port each launch would lose local
  storage.
- Finder-launched apps get launchd's PATH; the app reads the login
  shell's (`$SHELL -l -c`, five-second limit) before any kernel starts.
- The web view sends other hosts' links to the default browser and
  implements `alert`/`confirm`/`prompt`, which `WKWebView` drops without
  a UI delegate.
- CI builds ganymede-ffi from a pinned tlockney/ganymede ref on a macOS
  runner, then runs the XCTest suite: `ServerHost` against the real
  static library (page served through the token cookie, port closed after
  stop, start errors surfaced).
- Shared SwiftUI code with `#if os(macOS)` around AppKit; the iOS target
  comes after tlockney/ganymede#160.
