## 2026-11-07, Code font settings (#354)

Thomas asked for font choices in the apps: faces with ligatures and their
alternates, and an adjustable size. One setting now drives notebook cells
and text outputs (the page), the native text editor and the SwiftTerm
terminal: the face, the size, ligatures on or off, and the face's OpenType
stylistic sets and character variants.

The fonts are bundled, not taken from the system: WKWebView pages can't
rely on fonts the user installed, and iOS has none of these. All nine are
OFL. `scripts/fonts.py` fetches each from its upstream release (npm and
jsDelivr; GitHub release downloads aren't reachable from the agent
sandbox), pins it by SHA-256, converts it to WOFF2, cuts Iosevka to Latin
and code symbols (1 MB a style otherwise) and writes
`public/fonts/catalog.json`. The catalog labels each feature with the
font's own name for it where the font has one (JetBrains Mono, Monaspace),
a short hand-written list for Fira Code, Cascadia Code and Iosevka's sets,
and otherwise the characters the feature changes, read from its GSUB
lookups. Iosevka's character variants are left out: each has several
values, and its stylistic sets cover the common looks. Cascadia Code is
the Google Fonts build, which lacks the upstream's cursive italic (ss01).

The page and the Swift app read the same catalog. The page adds only the
chosen font's `@font-face`, and the service worker caches fonts on first
use instead of precaching 2 MB for everyone. In the apps the setting lives
in `UserDefaults`; each web view gets it in a document-start script, and a
change rewrites that script (so a reload keeps it) and calls
`window.ganymedeSetCodeFont`. Core Text gets the same WOFF2 files,
registered for the process; the variable fonts are asked for at weight
400, since Fira Code's and Monaspace's default instances are Light and
ExtraLight. SwiftTerm draws through Core Text runs and maps ligatures to
cells, so the terminal takes ligatures too.

⌘+, ⌘− and ⌘0 change the size from the View menu on the Mac and the iPad.
In a browser those keys stay the browser's zoom, so the size is set in the
Settings sheet.
