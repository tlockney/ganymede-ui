## 2026-11-11, cdp-kernel 0.10.0 and ganymede main for 0.7.0 (#480)

The apps and the e2e job use cdp-kernel 0.10.0, which adds
`jupyter.params`, `jupyter.result(name, value)` and `jupyter.host()`. It
bundles esbuild 0.28, so the lockfile's esbuild moves from cdp-kernel's
nested 0.25.12 to a top-level 0.28.2; no other package changes.

`GANYMEDE_REF` moves from 515c858 (ganymede#659) to 19cd144 (ganymede#669),
so the 0.7.0 apps link a ganymede-ffi with the host API's
notebooks.results, notebooks.run and grants. It goes back to a tag once
ganymede v0.8.0 is out, which saves the macos-app job's ganymede build.
