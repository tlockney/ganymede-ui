## 2026-11-28, Playwright WebKit + iPad/iPhone E2E suite (#918)

Added automated WebKit end-to-end coverage for the `#399` and `#273` browser/WebKit checklists alongside nightly macOS CI (`#918`):

- **Playwright projects and npm script (`playwright.config.ts`, `package.json`):** Kept default `npm run e2e` (`playwright test`) Chromium-only so Linux PR CI stays fast without WebKit installed. Added `"e2e:webkit": "E2E_WEBKIT=1 playwright test"` (also activated via `--project=webkit-*`), routing desktop specs to `webkit-desktop` (`Desktop Safari`, `1280×820`) and responsive eyebrow/layout checks across `webkit-ipad` (`820×1180`), `webkit-ipad-split` (`500×1180`), `webkit-iphone-portrait` (`390×844`), and `webkit-iphone-landscape` (`844×390`), all with `hasTouch: true`.
- **Nightly and manual macOS CI (`.github/workflows/e2e-webkit.yml`, `scripts/ci-changes.sh`):** Runs on `macos-latest` only on `schedule:` and `workflow_dispatch:`, reusing the pinned `GANYMEDE_VERSION` and `CDP_KERNEL_VERSION` from `.github/workflows/ci.yml`, caching WebKit in `~/Library/Caches/ms-playwright`, and uploading artifacts on failure. Skipped in `scripts/ci-changes.sh` so edits to `e2e-webkit.yml` do not trigger PR builds.
