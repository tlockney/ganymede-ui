## 2026-11-11, ganymede v0.8.0 pinned (#496)

The 0.7.0 release built the app against ganymede's `main` (19cd144),
because kernel registration and the host API were not in a ganymede
release yet. ganymede v0.8.0 has both, so `GANYMEDE_REF` is a tag again:
the macos-app job and release.yml download the release's
`GanymedeFFI.xcframework.zip` and check its `.sha256` instead of building
it with Rust, and the e2e job installs Ganymede 0.8.0.
