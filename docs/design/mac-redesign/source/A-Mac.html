2. Riders per day, by year

Average riders per day, January to September, each year against 2019.

const yearly = byYear.withColumns(
  pl.col("per_day").div(base2019).minus(1).mul(100).alias("vs_2019_pct"));

Plot.plot({
  y: { label: "riders per day (Jan–Sep)", grid: true },
  marks: [
    Plot.barY(yearly.toRecords(), { x: "year", y: "per_day", fill: (r) => (r.year === 2019 ? "#2747b8" : "#9fb0e6") }),
    Plot.ruleY([base2019], { strokeDasharray: "4 3" }),
  ],
})
SVG · 38 ms

Finding 1 (revised after sections 3 to 6). Riders are back, commuters are not. January to September 2026 averages 3,697 riders a day, 8% above 2019 (3,430) and the highest since the counter started. But the gain is weekends (+36%) and off-peak workday hours (+37% midday), while the 6–10 am commute is still 19% below 2019.
